小呆記帳 隱私權政策

最後更新：2026 年 11 月 11 日（新增 LINE 分帳空間清單）

小呆記帳是一個多人分帳的網頁應用程式。本政策說明我們會蒐集哪些資料、如何使用，以及你的選擇。

我們儲存的資料

  • 分帳資料：你在分帳空間中輸入的成員暱稱、群組、支出與還款紀錄。這些資料儲存在 Google Firebase（Cloud Firestore），並以「同步碼」區分不同的分帳空間。
  • LINE 帳號識別（僅在你使用 LINE 登入或從 LINE 開啟時）：我們只儲存 LINE 使用者 ID 經單向雜湊（SHA-256）後的值，用來在同一個分帳空間中自動辨識你是哪位成員。我們不儲存 LINE 使用者 ID 原文，也不儲存你的 LINE 顯示名稱、大頭貼或電子郵件。
  • 你的 LINE 分帳空間清單（僅在你綁定 LINE 時）：為了讓你在任何裝置用 LINE 登入後都能列出自己參與的分帳空間，我們會以 LINE 使用者 ID 的單向雜湊值為索引，儲存你綁定過的分帳空間的同步碼與你在該空間的成員名稱。這份清單只能用你的 LINE 使用者 ID 算出的雜湊值取得，無法被列舉。
  • 瀏覽器本機資料：你的同步碼、在各空間選擇的成員身分，以及最近使用的空間清單，只會存在你自己瀏覽器的 localStorage 中。

資料的使用方式

  • 只用於提供分帳功能：在不同裝置之間同步分帳資料，以及辨識你在分帳空間中的身分。
  • 不用於廣告、行銷或分析，也不會出售或提供給第三方。

誰看得到你的資料

知道同步碼的人都能讀取與修改該分帳空間的資料。請只把同步碼或邀請連結分享給一起分帳的人。

第三方服務

  • Google Firebase：儲存分帳資料。
  • LINE（LY Corporation）：提供 LINE 登入與在 LINE 中開啟本應用程式的功能。
  • GitHub Pages：提供網站託管。

你的選擇

  • 你可以不使用 LINE 登入，改以手動選擇成員的方式使用。
  • 你可以在應用程式中解除自己的 LINE 綁定，解除後該雜湊值即從分帳空間中刪除，該空間也會從你的 LINE 分帳空間清單移除。
  • 清除瀏覽器的網站資料，即可移除本機儲存的同步碼與身分。
  • 如需刪除整個分帳空間的資料，請透過下方聯絡方式提出。
